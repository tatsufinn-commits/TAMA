## 1. THE PHASE SEQUENCE (the spine of studio + practice)

```
PRE-DESIGN (Programming) → SITE ANALYSIS → SCHEMATIC DESIGN (SD)
   → DESIGN DEVELOPMENT (DD) → CONSTRUCTION DOCUMENTS (CD)
   → BIDDING/NEGOTIATION → CONSTRUCTION ADMINISTRATION (CA)
```
**Practice link:** these phases map to **SPP 201 (Pre-Design)** and **SPP 202 (Regular Services)** in the RA 9266 vault file — the same sequence governs fees and contracts (PP2).

## 2. PRE-DESIGN / PROGRAMMING (the most under-taught, most examinable)

**Purpose:** define the problem before designing — "problem seeking" (Mapúa's own program description).

**Activities:**
1. **Client/owner interviews** — needs, desires, budget, timeline.
2. **Project brief/program** — functions, spaces, areas (net → gross with circulation/efficiency factor).
3. **Space programming:** room-by-room areas; **space schematics / flow diagrams / bubble diagrams** — functional relationships, adjacencies, human/vehicular/material flows (ties to AR142-1P syllabus: functional relationships & activity circuits — verified in courses/).
4. **Feasibility studies** — budget, schedule, regulatory constraints.
5. **Zoning/regulatory check** — PD 1096/IRR (AMBF, PSO, setbacks — verified tables in vault), zoning ordinance, fire code, accessibility (BP 344).
6. **Deliverables:** program statement, adjacency matrix, bubble diagrams, preliminary budget, schedule.

**Key tools (memorize):**
- **Bubble diagram** — qualitative space relationships (not to scale).
- **Adjacency matrix** — desired/required/undesired proximities.
- **Efficiency ratio** — net usable ÷ gross area (typically 60–75% for office; varies by type).

## 3. SITE ANALYSIS (the site as a design driver)

**Data collection (the classic list):**
- **Natural:** topography/contours, soil, drainage/flood, vegetation, climate (sun path, wind — Amihan/Habagat), views.
- **Man-made:** utilities (water, power, sewer), access/circulation, adjacent uses, zoning/setbacks, easements, RROW.
- **Regulatory:** zoning classification, height limits, parking requirements, heritage zone constraints (RA 10066).

**Deliverables:** site analysis diagrams (sun/wind/access overlays), SWOT, **3 alternative site-plan concepts** (professional practice — McCormick source), site development plan (ties to AD6/Planning 1).

**PH specifics:** typhoon orientation, flood elevation, solar orientation E–W axis, prevailing-wind capture (TROPICAL-DESIGN file).

## 4. SCHEMATIC DESIGN (SD)

**Purpose:** "establish the general scope, conceptual design, scale and relationship of components" (professional definition).

**Activities:**
1. **Concept development** — the **parti** (central idea); concept statement.
2. **Massing studies** — physical/digital models; scale and site fit.
3. **Preliminary plans** — site plan, floor plans (bubble → plan), sections, elevations, perspective sketches.
4. **Preliminary systems selection** — structural grid, materials, MEPFS approach.
5. **Owner review + approval gate** (key checkpoint — the "design freeze" that prevents endless changes).

**Trap:** skipping schematic to jump to "pretty drawings" — SD is about *concept and relationships*, not finish.

## 5. DESIGN DEVELOPMENT (DD)

**Purpose:** "refine the chosen concept; develop detailed building systems."

**Activities:**
1. **Finalize layouts** — room sizes, circulation, dimensions.
2. **Systems coordination** — structural grid, MEPFS routing, envelope (ties: STRUCTURES + MEPFS + BT files).
3. **Material/finish selection** — with specifications direction.
4. **Detailed sections/elevations/details** — the assembly-level drawings (ties: BUILDING-ASSEMBLIES file).
5. **Updated cost estimate** (DD estimate — more accurate than SD).

**Interdisciplinary check:** this is where structural/MEP coordination happens (Layer 13 — knowledge-as-network).

## 6. CONSTRUCTION DOCUMENTS (CD) & BEYOND (practice link)

- **CD:** complete drawings + specifications + contract documents (ties: BT4 specs/QS, PP2, RA 9266 §32–33 signing/seal, ownership).
- **Bidding/negotiation; Construction Administration:** RFIs, shop drawings, change orders, payment certification (existing CONTRACTS-AND-BIDDING-DOCS file covers this).

## 7. COMMON MISTAKES (Layer 12)

| Trap | Fix |
|---|---|
| Designing before programming | Problem-seeking first; program is the contract with the client |
| Bubble diagram ≠ floor plan | Bubbles are qualitative; plans are measured |
| Net vs gross area confusion | Apply efficiency ratio; don't under-size circulation |
| Ignoring site climate in concept | Site analysis feeds the parti (PH: wind/sun/rain) |
| No owner approval gate at SD | Uncontrolled scope creep |
| Forgetting code check early | AMBF/PSO/setbacks before massing (verified vault tables) |
| Fee-phase confusion (PP2) | SD 15% / DD 20% (verify current UAP schedule of fees) |
