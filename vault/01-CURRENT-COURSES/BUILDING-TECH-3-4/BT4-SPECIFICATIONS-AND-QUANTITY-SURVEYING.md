## 1. WHAT BT4 COVERS (course scope)
1. **Specifications** — the written requirements for materials & workmanship (the "what & how well").
2. **Quantity surveying / estimating** — measuring quantities from drawings (the "how much").
3. **Bill of Quantities (BOQ)** — the priced document linking both → bidding (PP link).
4. **Cost estimation** — preliminary → detailed; unit-rate analysis.

## 2. SPECIFICATIONS (specs)

### 2.1 Types
| Type | Description | Use |
|---|---|---|
| **Descriptive** | Detailed written description of material/workmanship | Precise control; no brand |
| **Proprietary (brand)** | Names specific products/manufacturers | When performance is hard to specify; fast |
| **Performance** | States required performance criteria (tests/standards) | Innovation-friendly; needs verification |
| **Reference standard** | Cites codes/standards (ASTM, PNS, NSCP) | Combined with others |
| **Open vs closed** | Open = "or equal" options; closed = specific brands only | Contract strategy |

### 2.2 Specification-Writing Guidelines (from AAiT notes — VERIFIED list)
- Be **specific, not indefinite**; be brief; give all necessary facts; avoid repetition.
- Specify in the **positive form**; use correct grammar; direct rather than suggest.
- Use short rather than long sentences.
- **Do not specify both methods and results** (pick one control).
- Do not specify requirements **in conflict** with each other.
- Do not justify a requirement (state it).
- **Do not specify a result that contradicts the drawings** — specs + drawings must agree (the #1 coordination error).

### 2.3 Specs in the Contract-Document Set (PP2 link)
Specs are part of the contract documents with drawings and general conditions; they govern materials/workmanship disputes → architects' RFI/change-order work relies on them (RA 9266 §33 instruments-of-service context).

## 3. QUANTITY SURVEYING — THE PROCESS (VERIFIED — AAiT)
Four clearly defined steps in preparing a Bill of Quantities:
1. **Taking off** — measuring/scaling dimensions from drawings; recording on take-off sheets (timesing column, dimension column, squaring column, description column).
2. **Squaring** — arithmetic computation of the quantities.
3. **Abstracting** — collecting similar items into trade/work categories.
4. **Writing the final BOQ** — item description + unit + quantity + rate + amount.

**Take-off principles (Elbeltagi — VERIFIED):**
- Review EVERY drawing sheet; use a checklist to avoid omissions/double-counts.
- Highlight/mark areas where quantities have been determined.
- Add waste/loss separately from measured quantity (e.g., CHB ~5% waste → 13/m² practice).
- Use a systematic approach mirroring the construction sequence (foundation → structure → finishes).

**Standard measurement rules (VERIFIED, representative):**
- Excavation/earthwork: m³ (thickness > 30 cm) or m² (≤ 30 cm); soil-swelling factors (sand 5%, clay 15%, demolition 25%).
- Concrete: PC by volume m³ (thick) or area m² (slab < 20 cm); RC elements by m³ (except hollow-block slabs by m²); domes/shells by horizontal projection area.
- Masonry/blockwork: area m² (deduct openings > ~4 m² — half-area deduction for ≥4 m² openings; keep small openings).
- Steel: weight (kg/t) via bar-bending schedule (BBS).
- Wood: volume m³.
- **PH practice tie:** CHB walls ≈ 12.5 blocks/m² theoretical, ~13/m² with waste (verified vault file); mortar ~0.5–0.65 bags cement/m² (1:3 mix).

## 4. UNIT-RATE ANALYSIS (the cost engine)
```
Unit rate = (material cost + labor cost + equipment cost + overhead + profit) / quantity
```
**Components per item:**
- **Materials:** quantity × unit price (incl. waste factor).
- **Labor:** crew composition × productivity (output per day) → cost per unit; region-dependent (PH: mason + laborer day rates — time-sensitive, do not store as facts).
- **Equipment:** rental/operating cost per unit (PH: mixer, compactor, crane for high-rise).
- **Overhead & profit:** project overhead (JOOH — job office, supervision, permits) + general overhead + profit margin.

**Estimating classes (accuracy ladder):**
1. **Order-of-magnitude** (feasibility): ±30% — per m² rates.
2. **Preliminary/schematic** (±15–20%): assembly-level (per m² of wall, per m of footing).
3. **Detailed/definitive** (±5–10%): full take-off + unit rates (the BOQ).

## 5. WORKED EXAMPLE — CHB WALL QUANTITY (ties PH materials file)
**Problem:** Interior wall 4.0 m long × 3.0 m high (12 m²) with one door opening 0.9 × 2.1 m (1.89 m²). CHB 4". How many blocks, theoretical vs with waste?
- **Net wall area:** 12.0 − 1.89 = **10.11 m²**
- **Blocks theoretical:** 10.11 × 12.5 = **126.4 → ~127 blocks**
- **With 5% waste:** 127 × 1.05 = **133 blocks** (PH practice: ~13/m² → 10.11 × 13 = 131; use ~131–133)
- **Mortar (1:3):** ~0.5 bags/m² → ~5 bags (verify against current PH practice tables).

**Trap:** forgetting the opening deduction; using 12.5 without waste when the question asks "including waste."

## 6. COMMON MISTAKES (Layer 12)
| Trap | Fix |
|---|---|
| Specs contradicting drawings | Cross-check both before issue |
| Specifying both method AND result | Pick one control mode |
| Proprietary specs with no "or equal" | Use open specs unless justified |
| Take-off omissions (no checklist) | Systematic checklist per trade |
| Double-counting (highlighted items) | Mark measured areas |
| Forgetting waste factors | Add separately, documented |
| Opening-deduction rules misapplied | Deduct >4 m² fully, half for ≥4 m² (per measurement rule; verify local convention) |
| Mixing estimate classes | State accuracy class per stage |
| Using today's PH prices as facts | Prices are time-sensitive — always cite as "as of [date]" or exclude |
