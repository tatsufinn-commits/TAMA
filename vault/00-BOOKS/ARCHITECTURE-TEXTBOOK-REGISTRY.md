## 3. How to access legally (quick guide)

1. **Buy:** National Book Store (nbs.com.ph) for PH texts; publisher sites (Wiley, McGraw-Hill, Pearson, MIT Press) or Amazon for international.
2. **Borrow:** Mapúa University library (Intramuros/Makati); local public/university libraries.
3. **Preview/read legally online:** Google Books (google.com/books) — free previews; Open Library (openlibrary.org) — borrow legally via the lending system (never bypass the borrow wall).
4. **Public-domain editions** of older classics: Internet Archive / Project Gutenberg — see `PUBLIC-DOMAIN-CLASSICS.md`.

## 4. Explicitly EXCLUDED (never add)

- Pirate mirrors (Library Genesis, Z-Library, unauthorized file dumps).
- Scribd/CourseHero "downloads" of these titles.
- Any PDF of a commercially available book from an unlicensed source — **even for personal study, TAMA does not store these** (Rule 4; mission Access Policy §17).
