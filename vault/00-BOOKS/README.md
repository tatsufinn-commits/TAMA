# 00-BOOKS — ARCHITECTURE BOOK LIBRARY (LINKS-ONLY, COMPACT)

**Updated:** 2026-08-10
**Policy:** This folder is a **links-only** book library to keep the TAMA repository small and compact. **No PDFs are stored in the vault.** All linked books are either:
- **Public-domain classics** → free & legal on Internet Archive / Project Gutenberg (see `BOOKS-ONLINE-ACCESS.md`)
- **Commercial textbooks** (Max Fajardo, Ching, Neufert, etc.) → recorded with **legal access paths** only — never pirated (TAMA Rule 4)

## Structure


## How to use

1. Pick a book from `BOOKS-ONLINE-ACCESS.md` → open item page → download/read free.
2. For commercial books, follow the legal paths in the registry (NBS, publisher, library, Google Books preview).
3. To create curated knowledge: extract content **with page references** into small Markdown vault files (provenance per AI_RULES Law I). Keep the original book online; don't store the PDF.
