## How to use (for @curator / @mentor / @examiner / @drillmaster)

1. Open the item page link → "Download" → PDF → read/study.
2. For a curated vault file, extract definitions/principles/formulas from the PDF **with page references**, then save as a small Markdown file in the appropriate vault folder with provenance (per `docs/AI_RULES.md` Law I).
3. **Never** re-upload the PDF into the vault — keep `00-BOOKS/` links-only (repo compactness).
