## 1. WHY REGIONAL ARCHITECTURE MATTERS (course purpose)
Regional architecture connects global history to local identity: it explains how climate, culture, religion, materials, and trade shape building traditions — the conceptual bridge between HOA and PH architecture, vernacular studies, and critical regionalism (TOA link).

## 2. SOUTHEAST ASIA — THE REGIONAL FRAMEWORK

### 2.1 Shared conditions
- **Climate:** tropical monsoon — heat, humidity, heavy rain, typhoons → raised floors, steep roofs, deep eaves, permeable walls, natural ventilation.
- **Materials:** timber, bamboo, thatch (nipa, palm), woven panels — renewable, lightweight.
- **Culture:** Austronesian roots; later Indian/Chinese/Islamic/colonial layers; communal building traditions.

### 2.2 Key regional types (exam core)
| Type | Region | Features |
|---|---|---|
| **Rumah gadang** | Minangkabau, Sumatra | Horned/curved roof; raised on posts; matrilineal communal house |
| **Rumah panjang** | Borneo (Iban) | Longhouse — many families in one raised linear structure; verandah |
| **Torogan** | Maranao, PH (Lanao) | Royal house; panolong wing beams; okir carving (vault PH file) |
| **Bahay kubo / bahay na bato** | PH | Vernacular stilt hut → colonial hybrid (vault PH file — the PH anchor) |
| **Thai stilt house** | Thailand | Raised teak house; veranda; steep roof |
| **Balinese compound** | Bali | Open pavilions (bale) + family compound; temple hierarchy; cosmic orientation |
| **Khmer temple** | Cambodia | Stone temple-mountain (Angkor Wat) — Indian-derived cosmology |
| **Javanese pendopo** | Java | Open columned hall (the "pendopo") in palace/compound; tiered roof |
| **Vietnamese tube house / communal house (đình)** | Vietnam | Narrow urban house; village communal hall |
| **Burmese / Shan teak houses** | Myanmar | Raised teak, carved gables |

**Exam angle:** identify the type → region → climate/culture rationale (raised floor, roof form, materials).

### 2.3 SE Asian monumental traditions (Indian-derived)
- **Borobudur** (Java, 8th–9th c.) — Buddhist stupa-mountain; stepped mandala plan.
- **Angkor Wat** (Cambodia, 12th c.) — temple-mountain; moat; gallery reliefs; cosmology in plan.
- **Prambanan** (Java, 9th c.) — Hindu trimurti temple complex.
- **Shwedagon Pagoda** (Myanmar) — gilded stupa; terraced base.
- **PH parallel:** pre-colonial PH had no monumental stone temples of this scale (wooden, perishable) — a noted difference (scholarship; label as such).

## 3. ISLAMIC ARCHITECTURE — THE FRAMEWORK

### 3.1 Shared principles
- **Monotheism & aniconism** → no figural imagery in religious architecture; **calligraphy** and **geometry/arabesque** as decoration.
- **The mosque typology:** courtyard (sahn) + prayer hall (qibla wall → mihrab niche); minaret(s); hypostyle or iwan plan; dome over mihrab area.
- **Urban fabric:** the medina (dense, shaded streets); the souq/market; the caravanserai; the hammam; the madrasa (theological school); the palace (e.g., Alhambra).
- **Key structures:** pointed/horseshoe/ogee arches; **muqarnas** (stalactite/honeycomb vaulting — observed in TAMA AR123 quiz content); muqarnas dome; screens (mashrabiya); tilework (zellij); four-iwan plan (madrasas).

### 3.2 Key monuments (exam core)
| Monument | Location/Date | Feature |
|---|---|---|
| **Dome of the Rock** | Jerusalem, 691 | Earliest surviving Islamic monument; octagon + dome; mosaic |
| **Great Mosque of Samarra** | Iraq, 9th c. | Hypostyle; spiral minaret (malwiya) |
| **Ibn Tulun Mosque** | Cairo, 9th c. | Hypostyle; brick; pointed arches (early) |
| **Al-Azhar Mosque** | Cairo, 10th c. | University-mosque; hypostyle + domes |
| **Cordoba Mosque (Mezquita)** | Spain, 8th–10th c. | Double horseshoe arches; hypostyle forest |
| **Alhambra** | Granada, 13th–14th c. | Palace-fortress; courtyards (Court of the Lions); muqarnas; arabesque |
| **Suleymaniye Mosque** | Istanbul, 16th c. (Sinan) | Ottoman central dome + semi-domes; minarets |
| **Taj Mahal** | India, 17th c. | Mughal tomb; white marble; charbagh garden; onion dome |
| **Great Mosque of Djenne** | Mali, 14th c. (rebuilt 1907) | Sudano-Sahelian mud-brick; wooden scaffolding (toron) |

### 3.3 Islamic architecture in the PH (verified context)
- Southern PH mosque tradition (langgal — simple prayer house); sultanate-era timber construction; okir/ukkil ornament (vault PH file).
- No monumental domed mosques in pre-colonial PH (timber, perishable) — flag as scholarship.

## 4. COMMON MISTAKES
| Trap | Fix |
|---|---|
| "Islamic architecture = one style" | Regionally diverse (Moorish vs Ottoman vs Mughal vs Sahelian) |
| Muqarnas = "honeycomb decoration only" | It's structural-transitional vaulting (dome/arch transitions) |
| Horseshoe arch = Islamic invention | Roman/Visigothic precedents; Islamic made it iconic |
| Borobudur = temple "tower" | It's a stepped mandala mountain |
| Angkor = Indian import | Indian-derived cosmology but Khmer innovation |
| Torogan = bahay kubo | Different type/region (Maranao royal vs vernacular kubo) |
| Shwedagon = pagoda "like Borobudur" | Stupa (solid relic mound) vs stepped mandala temple |
