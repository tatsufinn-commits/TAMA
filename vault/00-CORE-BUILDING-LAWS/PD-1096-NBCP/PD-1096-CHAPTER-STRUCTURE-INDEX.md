## 2. High-Yield Sections for Mapúa Departmentals (per existing vault + verified text)

- **Sec. 101–105:** policy, scope, minimum standards — definitional MCQs.
- **Sec. 201–215:** Building Official powers, enforcement.
- **Sec. 301–311:** permits — building permit, certificate of occupancy (Sec. 305-306 area).
- **Sec. 701–710:** occupancy classification (the existing `RULE-7-8-ZONING-AMBF.md` covers the IRR Rule VII table — cross-reference).
- **Sec. 801–810:** requirements by occupancy.
- **Sec. 901–913:** yards, courts, lot occupancy (AMBF/setback concepts originate in this chapter).
- **Sec. 1001–1011:** light and ventilation (window areas, ceiling heights).
- **Sec. 1101–1108:** sanitation.
- **Sec. 1301+:** electrical; **Sec. 1601+:** plastics — utility-related MCQs.

## 3. Important Distinction (exam-critical)

- **PD 1096** = the statute (21 chapters; what this file indexes).
- **2005 Revised IRR of PD 1096** = the implementing rules (organized as Rules I–XIX), where most examinable *numbers* (tables, dimensions) actually live.
