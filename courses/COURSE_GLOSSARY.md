# COURSE_GLOSSARY — Terminology for Mapúa BS Architecture Study

**Compiled:** 2026-08-10 | **Usage:** reviewer-generation vocabulary base. Terms are grouped by course cluster; definitions are standard professional/educational usage (labeled "standard") unless observed in Mapúa materials ("observed").

## 1. Design & theory (AR141, AR142-1P, AR130P, AR132-1)

- **Anthropometrics** — human body measurements and proportions used to size spaces and objects (observed in AR142-1P syllabus).
- **Modular coordination** — dimensional system (standard module 100 mm / 4 in basis) aligning building components for coordination (observed AR142-1P).
- **Functional relationships / activity circuits** — how spaces relate and how users move between them; basis of bubble diagrams and adjacency matrices (observed AR142-1P).
- **Bubble diagram / adjacency matrix** — graphic tools for space relationships (standard).
- **Parti** — the central design concept/idea of a project (standard).
- **Programming** — pre-design phase: gathering requirements, constraints, goals (standard; "problem-seeking" per Mapúa program description).
- **Proxemics** — study of human use of space as cultural behavior (E.T. Hall) (observed TOA content).
- **Ordering principles** — axis, symmetry, hierarchy, rhythm, datum, transformation (standard).
- **Proportion / scale** — dimensional relationships; human scale (observed TOA).
- **Enclosure planes** — base, vertical, overhead planes defining space (observed TOA).
- **Semiology/semiotics** — study of signs and meaning in architecture (observed TOA).
- **Functionalism / formalism / regionalism / postmodernism** — theory movements (observed TOA2 postmodern content).
- **Schematic design / design development** — early project phases (standard, PP2 context).

## 2. History (AR120–AR124-1)

- **Post-and-lintel** — spanning system of two uprights and a horizontal beam (standard; Egyptian/Greek context).
- **Orders (Doric/Ionic/Corinthian)** — classical column-and-entablature systems (standard).
- **Ziggurat / mastaba / hypostyle hall** — Mesopotamian/Egyptian building types (observed).
- **Pendentive / squinch** — Byzantine dome transition devices (observed).
- **Rib vault / flying buttress / pointed arch** — Gothic structural devices (standard).
- **Muqarnas** — Islamic "honeycomb/stalactite" ornament (observed AR123).
- **Revivalism** — 18th–19th c. reuse of historical styles (observed AR123).
- **Vernacular architecture** — indigenous, climate/culture-responsive building (observed AR123 SE Asia).
- **Bahay kubo / bahay na bato** — Philippine vernacular/colonial house types (standard PH context).
- **National Artist for Architecture** — PH recognition for architects (standard; Filipino-architects doc observed).

## 3. Building technology (AR161–AR165-1P, VisCom, CAD/BIM)

- **Working drawings** — construction documents showing dimensions, materials, systems (standard).
- **Line weights / layers** — drawing convention hierarchy (standard; CAD context).
- **Foundation types** — spread, continuous, mat, pile (standard).
- **Roof framing** — trusses, rafters, purlins (standard).
- **Specifications (specs)** — written requirements for materials/workmanship (standard; BT4).
- **Quantity take-off** — measuring materials from drawings for estimating (standard; BT4).
- **BIM (Building Information Modelling)** — object-based 3D model + data workflow (observed AR117-1P).
- **Parametric design** — algorithmic design generation (observed AR113S essay content).
- **Tilt-up / prefabrication / modular construction** — alternative building systems (standard; BT5).
- **BERDE / LEED** — green building rating systems (standard).

## 4. Utilities (AR153P, BU2, AR155-1, PFC-01)

- **Upfeed / downfeed distribution** — water supply configurations (standard).
- **Soil/waste/vent stack** — sanitary drainage anatomy (standard).
- **Backflow prevention** — protection of potable supply (standard).
- **Branch circuit / feeder / service entrance** — electrical distribution elements (standard; PEC).
- **HVAC** — heating, ventilation, air conditioning (standard; PMC).
- **Reverberation time** — acoustic decay metric (seconds) (standard; BU3).
- **STC / IIC** — sound transmission / impact isolation class ratings (standard; BU3).
- **Lumen / lux / foot-candle** — lighting quantities (standard; BU3).
- **CRI / color temperature** — light quality metrics (standard; BU3).
- **Means of egress** — exit path components (standard; RA 9514).

## 5. Structures (MEC30–CE134P)

- **Free-body diagram** — isolated system showing forces (standard).
- **Stress / strain** — internal force intensity / deformation ratio (standard).
- **Flexure formula (σ = Mc/I)** — bending stress (standard; formula list below).
- **Determinate / indeterminate** — solvable by statics alone vs requiring compatibility (standard).
- **Load path** — how loads travel to foundations (standard).
- **Dead / live / wind / seismic loads** — load categories (standard; NSCP).
- **Lateral force resisting system** — shear walls, moment frames, bracing (standard; PH seismic context).
- **Development length / bar schedule** — rebar anchorage/detailing (standard; RC).

- **Setbacks / easements / lot coverage** — site development controls (standard).

- **Neighborhood unit** — community planning concept (standard).
