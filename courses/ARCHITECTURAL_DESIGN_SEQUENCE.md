## 3. Design progression logic (research-based interpretation)

Studio complexity progresses along five axes simultaneously [CHED template + standard architecture-education practice, labeled INF]:

1. **Scale/complexity:** abstract form → interiors → small buildings → space planning → site/landscape → community/urban → complex structures → thesis.
2. **Context awareness:** no site → generic site → real site analysis → environmental/landscape response → urban context → complex program.
3. **Technical integration:** design-only → anthropometrics (AR142-1P evidence) → materials (BT1 parallel) → utilities/structures integration → code compliance (senior studios) → full documentation.
4. **Representation skill:** manual graphics (VisCom/Graphic Design) → CAD (CAD10L/30L) → BIM (AR117-1P) → professional presentation.
5. **Process maturity:** guided exercises → programming → research-informed design (RMA + essays) → thesis.

## 4. What students do in studios (observed artifacts from Mapúa uploads) [Tier 4]

## 5. Design-course knowledge domains (for reviewer construction)

For each studio level, reviewer content should draw from (in order of evidence strength):
1. **Design process:** programming, site analysis, space planning, conceptual development (syllabus evidence for AD2; template for later levels).
2. **Anthropometrics & ergonomics:** AR142-1P explicitly (syllabus).
3. **Modular coordination:** AR142-1P explicitly (syllabus).
4. **Functional relationships / activity circuits / bubble diagrams:** AR142-1P explicitly (syllabus).
5. **Design elements & principles:** TOA1/TOA2 overlap (AR130P/AR132-1 content observed).
6. **Site planning & landscaping:** AD6 (template), Planning 1–3 (AR173 family).
7. **Community architecture & urban design:** AD7 (template), Planning 2–3.
8. **Complex-structure design:** AD8 (template), Structures chain.
9. **Thesis methodology:** Research Methods (AR134-1), Essays & Reviews (AR135-1), Thesis Research Writing (AR200).
10. **Presentation/documentation:** VisCom (AR113S/AR114S-1), CAD/BIM (AR117-1P), Graphic Design (AR101P).
