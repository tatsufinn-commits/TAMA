# 🔑 ANSWER KEY & DISTRACTOR TRAP ANALYSIS

### Question 1: Correct Answer = **B ($20\text{mm per meter}$ / $2\%$)**
* **Citation:** National Plumbing Code Section 704.4.
* **Rationale:** Horizontal drainage pipes $\le 100\text{mm}$ ($4"$) require a minimum $2\%$ ($1/4\text{ in/ft}$) slope.

### Question 2: Correct Answer = **C ($75\text{mm}$ / $3\text{ inch}$)**
* **Citation:** National Plumbing Code Table 7-2.
* **Rationale:** A water closet requires a minimum $75\text{mm}$ ($3"$) trap and waste branch ($100\text{mm}$ preferred for commercial batteries).

### Question 3: Correct Answer = **B ($2.0\text{ mm}^2$ / AWG #14 with 15A breaker)**
* **Citation:** Philippine Electrical Code (PEC) 2017 Section 2.10.
* **Rationale:** General lighting circuits use $2.0\text{ mm}^2$ (#14) copper wire protected by $15\text{A}$ breakers. Convenience outlets use $3.5\text{ mm}^2$ (#12) / $20\text{A}$.

### Question 4: Correct Answer = **B (8 to 10 outlets)**
* **Citation:** PEC 2017 Section 2.10.
* **Rationale:** General convenience outlet rating is assumed at $180\text{ VA}$ per duplex receptacle. At $230\text{V} \times 20\text{A} = 4,600\text{ VA}$, $80\%$ continuous load limit = $3,680\text{ VA} / 180\text{ VA} \approx 10\text{ outlets max}$.

### Question 5: Correct Answer = **B (30 TR)**
* **Calculation:** $\frac{360,000\text{ BTU/hr}}{12,000\text{ BTU/hr per TR}} = 30\text{ Tons of Refrigeration (TR)}$.

### Question 6: Correct Answer = **B ($15\text{ to }20\text{ CFM per person}$)**
* **Citation:** ASHRAE Standard 62.1 (Ventilation for Acceptable Indoor Air Quality).
* **Rationale:** Standard office density requires $15-20\text{ CFM/person}$ fresh outdoor makeup air.

### Question 7: Correct Answer = **B ($1.00\text{ second}$)**
* **Calculation:** $RT_{60} = \frac{0.161 \times 3,000}{483} = \frac{483}{483} = 1.00\text{ second}$.
* **Rationale:** An $RT_{60}$ of $1.0\text{s}$ is ideal for speech and lecture auditoriums.

### Question 8: Correct Answer = **D (At least $2.00\text{m}$ / $2,000\text{mm}$)**
* **Citation:** National Plumbing Code Section 906.
* **Rationale:** If a roof is accessible for roof garden or observation deck, vent pipes must extend at least $2.00\text{m}$ above the roof surface to prevent sewer gases from entering breathing zones.

### Question 9: Correct Answer = **A (Class I Standpipe)**
* **Citation:** NFPA 14 / RA 9514 Section 10.2.6.5.
* **Rationale:** Class I = $64\text{mm}$ ($2-1/2"$) for Fire Department; Class II = $38\text{mm}$ ($1-1/2"$) with hose cabinet for occupants; Class III = combination of both.

### Question 10: Correct Answer = **B (Pipe diameter reduction)**
* **Citation:** Hazen-Williams Hydraulic Equation ($h_f \propto d^{-4.87}$).
* **Rationale:** Friction loss is exponentially sensitive to pipe diameter reduction.
