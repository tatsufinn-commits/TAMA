### SITUATIONAL QUESTION 1: Allowable Maximum Building Footprint (AMBF)
**Project Brief:** A client intends to construct a 4-storey commercial retail building (Group E-2) on an **Inside Lot** located within a **C-2 (Commercial 2 / Medium Density)** zone. The Road Right-of-Way (RROW) is $15.00\text{m}$. The Total Lot Area (TLA) is $600.00\text{ sqm}$ with a lot frontage of $20.00\text{m}$ and depth of $30.00\text{m}$. No firewall is permitted on this lot.

Applying Table VII.1 of the 2004 Revised IRR of PD 1096 (NBCP), what is the Allowable Maximum Building Footprint (AMBF) in square meters?
* **A)** $300.00\text{ sqm}$
* **B)** $420.00\text{ sqm}$
* **C)** $450.00\text{ sqm}$
* **D)** $480.00\text{ sqm}$

### SITUATIONAL QUESTION 5: Travel Distance to Exit with Sprinklers
If the entire commercial retail building is fully protected with an approved automatic fire sprinkler system throughout, what is the maximum allowable travel distance from the most remote point on the floor to the nearest exit enclosure per RA 9514?
* **A)** $30.00\text{m}$ ($100\text{ft}$)
* **B)** $46.00\text{m}$ ($150\text{ft}$)

# 🔑 ANSWER KEY & DISTRACTOR TRAP ANALYSIS

### Question 1: Correct Answer = **C ($450.00\text{ sqm}$)**
* **Citation:** PD 1096 NBCP Rule VII, Table VII.1 (Maximum Allowable Percentage of Site Occupancy).
* **Calculation:** For a C-2 zone on an **Inside Lot without a firewall**, the Maximum Allowable Percentage of Site Occupancy (PSO) is **$75\%$**.
  $$\text{AMBF} = 600\text{ sqm} \times 0.75 = 450.00\text{ sqm}$$
* **Trap Analysis:**
  * Option A ($300\text{ sqm}$) is the $50\%$ PSO for R-1 residential lots.
  * Option B ($420\text{ sqm}$) uses $70\%$ PSO (R-2 inside lot limit).
  * Option D ($480\text{ sqm}$) uses $80\%$ PSO (applicable only to Corner Lots in C-2, not Inside Lots).

---

### Question 2: Correct Answer = **C (12 slots)**
* **Citation:** PD 1096 NBCP Table VII.5.
* **Calculation:** $\frac{1,200\text{ sqm GFA}}{100\text{ sqm/slot}} = 12\text{ parking slots}$.
* **Trap Analysis:** Option A uses a ratio of 1:200; Option B uses 1:120; Option D uses 1:60.

---

### Question 3: Correct Answer = **C ($9.60\text{m}$)**
* **Citation:** BP 344 Rule II (Pedestrian Ramps).
* **Calculation:** BP 344 strictly limits the maximum ramp slope to **$1:12$ ($8.33\%$)**.
  $$\text{Length} = \text{Rise} \times 12 = 0.80\text{m} \times 12 = 9.60\text{m}$$
* **Trap Analysis:**
  * Option A ($6.40\text{m}$) assumes an illegal $1:8$ slope.
  * Option B ($8.00\text{m}$) assumes an illegal $1:10$ slope.
  * Option D ($12.00\text{m}$) assumes a $1:15$ slope.

---

### Question 4: Correct Answer = **B ($1.12\text{m}$ / $1,120\text{mm}$)**
* **Citation:** RA 9514 Section 10.2.5.4.
* **Rationale:** For an occupant load of $\ge 50$ persons, the Fire Code mandates a minimum clear stair width of **$1.12\text{m}$**.
* **Trap Analysis:** Option A ($0.91\text{m}$) is permitted only for occupant loads of $<50$ persons; Option C ($1.20\text{m}$) is the BP 344 ramp width.

---

### Question 5: Correct Answer = **C ($61.00\text{m}$ / $200\text{ft}$)**
* **Citation:** RA 9514 Section 10.2.5.2 (Travel Distance to Exits).
* **Rationale:** Sprinkler protection extends the maximum travel distance limit from $46.00\text{m}$ ($150\text{ft}$) to **$61.00\text{m}$ ($200\text{ft}$)**.
