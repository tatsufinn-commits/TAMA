### QUESTION 1: Factored Ultimate Load Combination ($W_u$)

# 🔑 ANSWER KEY & DISTRACTOR TRAP ANALYSIS

### Question 1: Correct Answer = **C ($34.0\text{ kN/m}$)**
* **Calculation:** $W_u = 1.2(15.0) + 1.6(10.0) = 18.0 + 16.0 = 34.0\text{ kN/m}$.
* **Trap:** Option A is unfactored sum ($15+10=25$); Option B uses outdated 1.4D + 1.7L.

### Question 2: Correct Answer = **B ($153.0\text{ kN}\cdot\text{m}$)**
* **Calculation:** $M_u = \frac{W_u L^2}{8} = \frac{34.0 \times 6^2}{8} = \frac{34.0 \times 36}{8} = 153.0\text{ kN}\cdot\text{m}$.
* **Trap:** Option D uses $wL^2/4$; Option A uses $wL^2/12$.

### Question 3: Correct Answer = **B ($666,667\text{ mm}^3$)**
* **Calculation:** $S = \frac{b h^2}{6} = \frac{100 \times 200^2}{6} = \frac{100 \times 40,000}{6} = 666,666.67\text{ mm}^3$.
* **Trap:** Option D is the Moment of Inertia $I = \frac{bh^3}{12} = 66,666,667\text{ mm}^4$.

### Question 4: Correct Answer = **C ($12.0\text{ MPa}$)**
* **Calculation:** $\sigma = \frac{M}{S} = \frac{8,000,000\text{ N}\cdot\text{mm}}{666,667\text{ mm}^3} = 12.0\text{ N/mm}^2 = 12.0\text{ MPa}$.
* **Trap:** Forgetting to convert $\text{kN}\cdot\text{m}$ to $\text{N}\cdot\text{mm}$ causes a $10^6$ unit error.

### Question 5: Correct Answer = **C ($25.0\text{ kN}\cdot\text{m}$)**
* **Calculation:** $M_u = \frac{W_u L^2}{2} = \frac{8.0 \times 2.5^2}{2} = \frac{8.0 \times 6.25}{2} = 25.0\text{ kN}\cdot\text{m}$.
* **Trap:** Dividing by 8 instead of 2 yields Option A ($6.25\text{ kN}\cdot\text{m}$).

### Question 6: Correct Answer = **B ($74.0\text{mm}$)**
* **Calculation:** $a = \frac{A_s f_y}{0.85 f'_c b} = \frac{1,200 \times 275}{0.85 \times 21 \times 250} = \frac{330,000}{4,462.5} = 73.95\text{mm} \approx 74.0\text{mm}$.

### Question 7: Correct Answer = **B ($40\text{mm}$)**
* **Citation:** NSCP 2015 Section 420.6.1.3.
* **Rationale:** Non-exposed beams and columns require $40\text{mm}$ ($1.5\text{ in}$) clear cover. Slabs require $20\text{mm}$; earth-cast footings require $75\text{mm}$.

### Question 8: Correct Answer = **B ($-\frac{1}{10} W_u L_n^2$)**
* **Citation:** NSCP 2015 Section 406.5.2 (Simplified Frame Analysis).
* **Rationale:** ACI coefficient for the negative moment at the exterior face of the first interior support is $-1/10 w L_n^2$.

### Question 9: Correct Answer = **C ($200\text{mm}$ / $h/2$)**
* **Rationale:** In symmetrical rectangular homogeneous elastic sections, the neutral axis passes exactly through the centroid ($h/2$).

### Question 10: Correct Answer = **D ($0.90$)**
* **Citation:** NSCP 2015 Section 421.2.1.
* **Rationale:** Tension-controlled flexure ($\phi = 0.90$). Compression-controlled columns with ties use $\phi = 0.65$; spiral columns use $\phi = 0.75$.
