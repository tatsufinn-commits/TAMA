# 🔑 ANSWER KEY & DISTRACTOR TRAP ANALYSIS

### Question 1: Correct Answer = **B ($20.5\text{ MPa}$ / $3,000\text{ psi}$)**
* **Citation:** ACI 318 Section 18.18 / NSCP 2015 Section 418.18.
* **Rationale:** The code establishes a minimum $20.5\text{ MPa}$ ($3,000\text{ psi}$) threshold before post-tensioning transfer forces can be safely applied to prevent localized anchorage zone crushing.
* **Trap:** Option A is insufficient; Option D is the 28-day full cure strength.

### Question 2: Correct Answer = **B ($24\text{ inch}$ nominal depth, $84\text{ lbs}$ weight per linear foot)**
* **Citation:** AISC Steel Construction Manual.
* **Rationale:** In American Imperial $W$-shape designations, the first number is nominal depth in inches ($24"$) and the second number is weight in pounds per linear foot ($84\text{ lbs/ft}$).

### Question 3: Correct Answer = **B ($75\text{mm to }125\text{mm}$ / $3\text{ to }5\text{ inches}$)**
* **Citation:** ASTM C143 / ACI 301.
* **Rationale:** Beams and slabs require $75-125\text{mm}$ slump. $25-50\text{mm}$ is for heavy unreinforced mass footings; $>175\text{mm}$ risks bleeding/segregation unless superplasticizers are added.

### Question 4: Correct Answer = **B (ASTM A325)**
* **Citation:** AISC Specification for Structural Joints / ASTM A325.
* **Rationale:** ASTM A325 is the industry standard high-strength structural bolt. (ASTM A307 is mild carbon steel for light framing).

### Question 5: Correct Answer = **B (Division 04)**
* **Citation:** CSI MasterFormat 50-Division System.
* **Rationale:** Division 03 = Concrete, Division 04 = Masonry, Division 07 = Thermal & Moisture Protection, Division 09 = Finishes.

### Question 6: Correct Answer = **D ($75\text{mm}$ / $3\text{ inches}$)**
* **Citation:** NSCP 2015 Section 420.6.1.3 / ACI 318.
* **Rationale:** Concrete cast permanently against earth requires a minimum $75\text{mm}$ ($3\text{ in}$) clear cover to protect steel from soil moisture and corrosive salts.

### Question 7: Correct Answer = **B ($1 : 2.0$)**
* **Citation:** Philippine DPWH Standard Specifications / Building Tech 1.
* **Rationale:** Class A mortar = 1 part cement : 2 parts sand. (Class B is 1:3; Class C is 1:4).

### Question 8: Correct Answer = **B (Structural Silicone Sealant)**
* **Citation:** Building Technology 4 / Architectural Glazing.
* **Rationale:** High-modulus structural silicone sealant is the only material engineered to chemically bond glass to metal and transfer wind suction forces. Setting blocks only support dead weight.

### Question 9: Correct Answer = **B (Check)**
* **Citation:** Building Technology 1 / Timber Construction.
* **Rationale:** A Check is a radial separation across growth rings due to seasoning. A Shake occurs *between* annual rings.

### Question 10: Correct Answer = **C (Isolated Reinforced Concrete Spread Footings)**
* **Citation:** Foundation Engineering / Building Technology 2.
* **Rationale:** For a low-rise 3-storey building with $150\text{ kPa}$ bearing capacity, isolated spread footings are the most economical shallow foundation. Piles and mats are unnecessary over-engineering.
